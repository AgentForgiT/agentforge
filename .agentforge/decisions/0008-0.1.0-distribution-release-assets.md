# DEC-0008: 0.1.0 Distribution — Release Assets Until PyPI Token

Metadata:

- Status: Accepted
- Date: 2026-08-01
- Deciders: AgentForge maintainers
- Related: DEC-0006 (0.1.0 gate), ADR-0027 (SDK distribution)

## Decision

For the `0.1.0` release, `agentforge-sdk` and `agentforge-cli` ship **as GitHub release assets** (wheels + sdists attached to every Genesis tag by the tag-gated publish workflow). PyPI publication is **deferred** until the maintainer provisions the `PYPI_TOKEN` repository secret; the workflow's publish step is already token-gated and dry-run-safe (ADR-0027), so enabling it later is a settings change, not a code change.

This satisfies exit criterion 1 of DEC-0006 ("SDK + CLI publishable ... or an explicit recorded decision to keep them on release assets only").

## Rationale

- The wheels are already built, verified (fresh-venv install), and attached to releases.
- No PyPI account/token exists for the project yet; inventing or requiring one would block 0.1.0 on an external account step.
- The audit trail stays honest: this is a recorded decision, exactly the deferral path DEC-0006's gate allows.

## Consequences

- `pip install <release-asset-url>` is the supported install path for 0.1.0.
- PyPI publication is one settings change away (add `PYPI_TOKEN`); the workflow needs no edits.
- The gate checklist records this decision as evidence for box 1.
