# DEC-0009: Public 1.0.0 Readiness Gate

Metadata:

- Status: Accepted
- Date: 2026-08-01
- Deciders: AgentForge maintainers
- Issues: #210, #211, #212, #213, #214
- Related: DEC-0006 (0.1.0 gate), requirements/1.0.0-readiness-gate.md

## Decision

Ship **1.0.0** as the stability line, gated by the audit criteria in the readiness requirements:

1. All suites green offline (gateway, CLI, SDK, benchmarks) + CI Bootstrap Validate.
2. No Draft ADRs/DECs in the decision register.
3. Docs complete (gateway, CLI, SDK, AICS, MCP, compatibility, community).
4. Distribution working (wheels on releases via the automated publish workflow).
5. AICS Level-3 on the AgentForge repo, CI-validated.
6. API-surface inventory — the backward-compatibility contract for the 1.x line.
7. RELEASE-1.0.0.md records the transition and this decision.

From 1.0.0 onward: **breaking changes require a minor bump and an ADR**; the 0.x feature line ends; patch releases are 1.0.x.

## Rationale

0.1.0 made the platform adoptable; 1.0.0 makes it dependable. The gate exists to keep the stability claim honest — no date, only verifiable artifacts. The project is 38 ADRs deep across 12 feature releases; the API surface (gateway dual-protocol + MCP, seven CLI commands, SDK, AICS v0.2) is the contract worth freezing.

## Alternatives Considered

- **Skip 1.0.0, stay on 0.x forever** — rejected: semver's own convention says 0.x means "unstable"; the project has earned the stability line and its adopters need the commitment.
- **1.0.0 with unresolved Draft ADRs** — rejected: a stability line with open drafts is not stable; the audit must be clean.

## Consequences

- Adopters get a frozen, documented API surface and the semver promise.
- Future features (twin service extensions, MCP client mode, variance tooling) ride 1.x under the minor-bump rule.
- The decision register grows to 9 DECs; the audit trail stays the project's spine.

## Deferred

- A formal compatibility test suite (API-surface diffing) — the inventory is v1; automated diffing can follow.
- LTS/support-policy document beyond the semver promise.
